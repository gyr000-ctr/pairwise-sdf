# pairwise-sdf

## 题面（可直接粘贴）

2D 距离场。约束：圆/矩形/线段有符号距离正确、内部为负；必须支持并/交/差布尔运算与平滑最小（k 可调）；提供梯度与法线；10 万次求值不超过 200 ms；并发安全；非法尺寸、非有限坐标、退化线段要给出可区分的错误。验收：python -m pytest tests -q -k sdf。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万次耗时
- 并发
- 极大坐标
- 非有限输入
- 退化矩形
